# Плетіння — мод для Minecraft 1.21.1 (Fabric)

Магічна система з новели «Чудернацькі місця світу»: мана, провідність, точність, сприйняття, сім рангів, дванадцять напрямів, п'ять законів, закляття, які маг складає сам, а також драконяча мова, угоди з духами, свята магія та аура.

## Встановлення

1. Встановіть **Fabric Loader** для Minecraft **1.21.1** (fabricmc.net).
2. Покладіть у папку `mods` файл `pletinnya-0.2.0.jar` і **Fabric API** для 1.21.1.
3. Запустіть гру з профілем Fabric.

Готовий `.jar` автоматично збирається на сторінці Releases цього репозиторію.

## Керування

| Клавіша | Дія |
|---|---|
| **K** | Скрижаль: формули, ручне плетіння, характеристики, шляхи |
| **R** | Сплести обране закляття |
| **G / H** | Наступна / попередня формула |
| **B** | Голос дракона (драконяча мова) |
| **V** | Аура |
| **N** | Розпустити власні плетіння (з рангу II) |
| Присісти й стояти | Медитація, тобто збирання мани довкілля |

З посохом у руці закляття плететься на ПКМ, а наступна формула обирається через Shift+ПКМ.

## Плетіння

**Закляття = Задум + Формула + Живлення.** У Скрижалі (K, вкладка «Формула») обирається:
- **напрям**: Вода, Вогонь, Вітер, Земля, Блискавка, Лід, Природа, Звук, Світло, Темрява, Кров, Мана;
- **форма**: Снаряд, Область, На себе, Дотик, Конструкт;
- **параметри**: Сила, Розмір, Дальність, Тривалість;
- **умова**: одразу, із затримкою або при наближенні (з рангу IV).

Діаграма ниток показує будову формули, а поруч видно складність, ціну, провідність і ризик збою. Нову формулу можна сплести, лише коли Скрижаль є в інвентарі.

**Ручне плетіння** (вкладка «Вручну»). Скрижаль показує візерунок вузлів формули. Його треба запам'ятати й повторити. Точність стає якістю плетіння, а висока якість зменшує ризик збою й ціну.

**П'ять законів:** ціна (наявна речовина здешевлює плетіння), розуміння (складність обмежена рангом і досвідом напряму), опір (сильні істоти опираються), навантаження (кількість одночасних плетінь), наслідок (перевищення провідності пошкоджує канали, помилки у формулі змінюють закляття).

**Ефекти.** Кожен напрям має власні частинки й візерунки. Під магом спалахує коло з сигілами. Вогонь вибухає жаром, лід розлітається уламками, блискавка б'є з неба розгалуженим розрядом, звук розходиться хвилями, темрява затягує в себе, мана постає шестикутним куполом. Снаряди світяться образом своєї есенції.

## Особливі шляхи

- **Драконяча мова (B).** Слова напряму, форми й «РА» для сили, наприклад `ВАР ТУН РА`. Закони розуміння тут не діють і збоїв немає, але тіло зазнає навантаження. Слова відкривають драконячі кодекси.
- **Магія духів.** Святилище духів і печатка угоди: дух місця (його напрям залежить від біому) бере частину розрахунків на себе, тож закляття стають дешевшими й стабільнішими. У небезпеці дух захищає, але має власну волю.
- **Свята магія.** Вівтар святості й святий символ: присвятіть себе Еліасу, Луміс або Золотому Богу Драконів. Щоденні молитви й пожертви дають віру, а за віру діють молитви: по три для кожного божества.
- **Аура (V).** Підсилює тіло й удари в ближньому бою, а кожен четвертий удар розходиться хвилею. Клинок аури подвоює силу ударів.

## Одяг і посохи

**16 сетів магічного одягу** з власними 3D-моделями: каптури, капелюхи, митра, мантії з табардами, плащі, наплічники. Кожна частина здешевлює закляття свого напряму, а повний сет дає особливу властивість (див. підказку предмета). Рецепт: вовна або шкіра плюс есенція шляху.

**19 посохів із 3D-моделями:** по одному на кожен напрям (закляття свого напряму на 20% дешевші), скіпетр Драконячого Ікла, ліхтар духів, сонячний скіпетр, клинок аури й три посохи рангів.

## Світ

Руда кристалів мани й кластери. **8 структур:**
- вежа мага;
- коло вузла;
- храм святості;
- хатинка Аврори на пні;
- руїни Академії магії;
- драконяче святилище;
- гай духів;
- підземне сховище ткача.

Знайти структуру: `/locate structure pletinnya:aurora_hut` (решта назв аналогічні).

`/pletinnya stats`, `/pletinnya rank <гравці> <1-7>`, `/pletinnya mana <гравці>`, `/pletinnya reset <гравці>`.
